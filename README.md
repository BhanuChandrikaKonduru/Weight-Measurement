# Weight Measurement System Using Load Cells

This project demonstrates the design of a weight sensing system using load cells and HX711 modules, aimed at providing accurate and stable weight measurements with minimal hardware usage.

## Project Overview
- Designed a weight measurement setup using HX711 ADC modules and load cells.  
- Implemented optimized switching to reduce the number of HX711 modules required.  
- Interfaced the system with a microcontroller for real-time weight readings with improved stability.
